# TodoListApp
Приложение для ведения списка задач

## Стэк
+ Xcode
+ Swift
+ UIKit
+ CoreData

## Цели и задачи
+ доработка приложения с использованием базы данных CoreData для хранения списка задач
+ изучение паттерна Singleton
+ создание синглтона StorageManager для ведения базы данных
